# ⚡ SiteCloner SaaS v2

> Complete offline website cloner with 3D WebGL asset extraction, media downloader, tracker stripping, and local preview management.

## ✨ Features
- **1-Click Cloning**: Fast multi-threaded resource download.
- **Deep 3D & Media Discovery**: Detects `.glb`, `.gltf`, `.drc`, `.ktx2`, `.exr`, `.hdr`, `.riv`, `.woff2`, `.mp4`, `.mp3`.
- **Clean Offline Ready**: Strips Google Tag Manager/Analytics and converts asset paths to relative.
- **Live Preview Servers**: Dedicated HTTP server auto-allocated per site.
- **ZIP Export**: Export any cloned site as an archive.
- **GitHub Integration**: 1-click publishing to GitHub repositories.

## 🚀 Quick Start
```bash
# Install dependencies
pip install -r requirements.txt

# Start the web app
python app.py
```
Or simply double-click `start.bat` on Windows.
Open `http://localhost:5000` in your browser.
